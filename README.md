# skills

Agent skills (`SKILL.md`) for coding agents, maintained by Dean Stone.

Work in progress: this repo is a scaffold. No skills have been added yet.

## What will live here

- **Authored skills.** Written and maintained here.
- **Imported skills.** Taken from upstream repos, either unchanged or edited to fit my set-up and preferences. Each import records its upstream repo, path and pinned commit in a lockfile, keeps the upstream licence, and takes upstream updates by three-way merge against the pinned commit, so local edits survive.

## Development

Trunk-based: small commits straight to `main`. Releases are cut from the `deploy` branch (not created yet).
